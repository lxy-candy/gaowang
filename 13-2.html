SVG 矢量图标

Lucide 图标输出的是真正的 SVG 标记：先写占位符 <i data-lucide="图标名"></i>，脚本执行 createIcons() 后会把它替换为 <svg> 元素， 描边使用 currentColor，因此用 CSS 的 color、 width/height、stroke-width 都能精确控制。脚本已下载到本地 cdn/lucide/lucide.min.js，页面不依赖外部网络。

1. 使用方式（占位符 → SVG）

<script src="cdn/lucide/lucide.min.js"></script>

<i data-lucide="home"></i>   /* 渲染前：<i> 占位符 */

<script>
    // 调用库把占位符替换为 <svg> 元素
    lucide.createIcons({ icons: lucide.icons });
</script>
