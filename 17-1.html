JSON.parse()

                
把 JSON 字符串解析成 JS 对象


const str = '{"a":1}';
const obj = JSON.parse(str);
console.log(obj.a);  // 1

JSON.stringify()

                
把 JS 对象转成 JSON 字符串（第三个参数控制缩进）


const obj = { a: 1, b: "Hi" };
JSON.stringify(obj, null, 2);
// '{\n  "a": 1,\n  "b": "Hi"\n}'

fetch + .json()

                
从服务器获取 JSON 并解析（课程场景可用本地 JSON 文件模拟）


fetch('data.json')
  .then(r => r.json())
  .then(data => {
    console.log(data);
  });

用 JSON 做深拷贝

                
先 stringify 再 parse 就能得到一个完全独立的副本（函数会丢失）


const copy = JSON.parse(
  JSON.stringify(obj)
);
// copy 和 obj 互不影响
