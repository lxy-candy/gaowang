13-1 · Font Awesome 字体图标

字体图标 Font Icon

Font Awesome 把图标做成一套字体文件：每个图标对应一个字符编码，用 <i class="fa-solid fa-图标名"> 像写文字一样输出图标，因此可以像字体一样用 color、font-size 控制颜色与大小。样式表与字体文件已下载到本地 cdn/font-awesome/，页面不依赖外部网络。

1. 使用方式（本地字体图标）

<link rel="stylesheet" href="cdn/font-awesome/css/all.min.css">

<i class="fa-solid fa-house"></i;   /* 实心 */
<i class="fa-regular fa-heart"></i;  /* 线框 */
<i class="fa-brands fa-github"></i;  /* 品牌 */
