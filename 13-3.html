13-3 · Iconfont 字体图标底部导航

字体图标 · @font-face

图标来自本项目 font/font_5244874_dxs3wbl8ev/ 下的 iconfont 字体文件， 用 @font-face 引入本地 woff2 / woff / ttf，再以 ::before 输出字形编码。页面底部是一条全屏宽度、固定定位、纯色实体背景 的移动端下导航：4 个导航项用 flex 等分自适应屏宽，每项自带数字徽章与右上角红点， 尺寸用 clamp() 随屏宽缩放，并预留 iOS 安全区。点击导航项可切换选中态。

1. 导航结构

<nav class="lxy_tabbar" aria-label="底部导航">
    <a class="lxy_tab lxy_active" href="#">
        <span class="lxy_ico">
            <i class="lxy_if lxy_if-home"></i>   /* 字体图标字形 */
            <span class="lxy_num">8</span>       /* 数字徽章 */
            <span class="lxy_dot"></span>        /* 右上角红点 */
        </span>
        <span class="lxy_tab_text">首页</span>
    </a>
    /* 其余 3 项：分类 / 购物车 / 我的，结构完全相同 */
</nav>

2. 关键样式：全屏固定 + flex 等分 + 响应式尺寸

.lxy_tabbar {
    position: fixed;            /* 固定在视口底部，始终可见 */
    left: 0; right: 0; bottom: 0;
    width: 100%;                /* 全屏宽度 */
    display: flex;              /* 4 项水平排列 */
    background: #fff;           /* 固体（不透明）背景 */
    border-top: 1px solid var(--lxy-line);
    padding-bottom: env(safe-area-inset-bottom);
}

.lxy_tab { flex: 1 1 0; min-width: 0; }   /* 等分剩余宽度，自适应任意屏宽 */

.lxy_ico {
    font-size: clamp(22px, 6vw, 27px);  /* 图标随屏宽缩放，320~414px 皆合适 */
    width: 1em; height: 1em;            /* 盒子等于字号，字形刚好填满 */
}

3. 图标引入：@font-face + 字形编码

@font-face {
    font-family: "lxy_iconfont";
    src: url("font/font_5244874_dxs3wbl8ev/iconfont.woff2") format("woff2"),
         url("font/font_5244874_dxs3wbl8ev/iconfont.woff")  format("woff"),
         url("font/font_5244874_dxs3wbl8ev/iconfont.ttf")   format("truetype");
}

.lxy_if { font-family: "lxy_iconfont" !important; }
.lxy_if-home::before { content: "\e64f"; }   /* 首页 shouye */
.lxy_if-cat::before  { content: "\e828"; }   /* 分类 catalog */

4. 同一套导航在不同屏宽下的表现

上图为同一段导航代码克隆到 320 / 375 / 414 宽的“屏幕”中：宽度 100% + flex 等分， 无论屏宽如何变化，4 项始终平分整条导航；真正使用时它是页面底部固定定位的那一条。

5. 导航用到的字形对照

首页icon-shouye · \e64f
分类icon-catalog · \e828
购物车icon-cart-full · \e827
我的icon-customer-interests · \e82d

6. 徽章与红点

.lxy_num 是绝对定位在图标盒子上的圆角胶囊（红底白字 + 白描边）， 用 clamp() 控制高度与字号，数字过长时自动加宽； .lxy_dot 是 9px 的红色圆点，定位在图标盒子的右上角外侧。 两者都加了与导航同色的描边，压在图标边缘上时轮廓依然清晰。 点击任意导航项即可切换选中态（脚本用事件委托，克隆到演示屏里的导航同样可点）。
