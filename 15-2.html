① 条件语句（Branching）

if … else if … else

最常用的多分支判断。输入一个分数，自动给出评级。

// 输入分数，输出等级
let score = Lxy_inputNum;
if (score >= 90) console.log("优秀 A");
else if (score >= 80) console.log("良好 B");
else if (score >= 60) console.log("及格 C");
else console.log("不及格 D");

switch … case

当分支条件是同一个变量的不同取值时，switch 比 if-else 更清晰。

let day = new Date().getDay();
switch (day) {
  case 0: console.log("周日"); break;
  case 1: console.log("周一"); break;
  case 2: console.log("周二"); break;
  default: console.log("工作日");
}

② 循环语句（Looping）

for（计数循环）

最经典的循环，已知循环次数时首选。这里求 1~10 的累加和。

let sum = 0;
for (let i = 1; i <= 10; i++) {
  sum += i;
}
console.log("1+2+…+10 = " + sum);

while（条件循环）

先判断后执行，只要条件成立就一直跑。累加出第一个超过 50 的自然数之和。

let total = 0, n = 1;
while (total <= 50) {
  total += n;
  n++;
}
console.log("加到 " + (n-1)
  + " 时总和 = " + total);

do … while

先执行一次再判断，至少跑一遍。随机掷骰子直到掷出 6，看看需要几次。

let count = 0, dice;
do {
  dice = Math.floor(Math.random()*6) + 1;
  count++;
} while (dice !== 6);
console.log("第 " + count +
  " 次掷出了 6");

for … of（遍历可迭代对象）

ES6 推荐方式，直接拿到每个元素的值，无需索引。遍历数组。

const fruits = ["🍎 苹果", "🍌 香蕉",
  "🍇 葡萄", "🍓 草莓"];
let list = "";
for (const f of fruits) {
  list += f + " → ";
}
console.log(list);

for … in（遍历对象键）

专门遍历对象的属性名（key）。用于数组时拿到的是索引，不推荐。

const student = {
  name: "刘馨月",
  age: 20,
  grade: "大二",
  major: "数字媒体"
};
let info = "";
for (const key in student) {
  info += key + ": " + student[key] + "\n";
}
console.log(info);

break & continue

break 跳出整层循环；continue 跳过本次迭代继续下一次。输出 1~20 之间不是 3 的倍数的奇数。

let result = "";
for (let i = 1; i <= 20; i++) {
  if (i % 2 === 0) continue; // 跳过偶数
  if (i % 3 === 0) continue; // 跳过3的倍数
  result += i + "";
  if (result.length > 40) break;
}
console.log(result);
