⏱ setTimeout() — 延迟一次
在指定的延迟时间后**只执行一次**回调函数。常用于：延迟提示、动画延迟、轮询检测等。返回一个 timeoutId，可用 clearTimeout(id) 取消。
const id = setTimeout(() => { console.log('2秒后打印'); }, 2000); // clearTimeout(id); // 取消
🔁 setInterval() — 循环执行
每隔指定间隔**重复执行**回调，直到被清除。常用于：倒计时、轮询刷新、动画帧更新等。返回 intervalId，可用 clearInterval(id) 取消。
const id = setInterval(() => { console.log('每秒打印一次'); }, 1000); // clearInterval(id); // 取消
