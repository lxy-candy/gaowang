13-4 · SVG 雪碧图底部导航

SVG · symbol + use

与 13-3 是同一条底部导航，只是图标改用 SVG 方案：把 iconfont 项目导出的 iconfont.js 里的 4 个 <symbol> 内联到页面，组成 SVG 雪碧图， 导航项里用 <svg><use href="#lxy_icon_home"></use></svg> 引用。 路径没有写死颜色，外层 fill: currentColor 让图标跟随导航项的文字颜色变化。 底部导航同样是全屏宽度、固定定位、纯色实体背景，flex 等分 4 项， 带数字徽章与右上角红点，尺寸随屏宽自适应。

1. 导航结构

<nav class="lxy_tabbar" aria-label="底部导航">
    <a class="lxy_tab lxy_active" href="#">
        <span class="lxy_ico">
            <svg class="lxy_svg"><use href="#lxy_icon_home"></use></svg>
            <span class="lxy_num">8</span>       /* 数字徽章 */
            <span class="lxy_dot"></span>        /* 右上角红点 */
        </span>
        <span class="lxy_tab_text">首页</span>
    </a>
    /* 其余 3 项：#lxy_icon_cat / #lxy_icon_cart / #lxy_icon_me */
</nav>

2. 关键样式：全屏固定 + flex 等分 + 响应式尺寸

.lxy_tabbar {
    position: fixed;            /* 固定在视口底部，始终可见 */
    left: 0; right: 0; bottom: 0;
    width: 100%;                /* 全屏宽度 */
    display: flex;              /* 4 项水平排列 */
    background: #fff;           /* 固体（不透明）背景 */
    border-top: 1px solid var(--lxy-line);
    padding-bottom: env(safe-area-inset-bottom);
}

.lxy_tab { flex: 1 1 0; min-width: 0; }   /* 等分剩余宽度，自适应任意屏宽 */

.lxy_ico  { width: clamp(22px, 6vw, 27px); height: clamp(22px, 6vw, 27px); }
.lxy_svg  { width: 100%; height: 100%; fill: currentColor; }

3. SVG 雪碧图：symbol 定义 + use 引用

<!-- 隐藏在页面顶部的 symbol 集合（路径取自 iconfont.js） -->
<svg class="lxy_sprite" aria-hidden="true">
    <symbol id="lxy_icon_home" viewBox="0 0 1024 1024">
        <path d="M969.6 502.4l-118.4-112-323.2-300.8c-9.6-9.6..."/>
    </symbol>
    /* 另有 lxy_icon_cat / lxy_icon_cart / lxy_icon_me */
</svg>

<!-- 导航项中只需一行即可复用符号 -->
<svg class="lxy_svg"><use href="#lxy_icon_home"></use></svg>

4. 同一套导航在不同屏宽下的表现

同一段导航代码克隆到 320 / 375 / 414 宽的“屏幕”中：宽度 100% + flex 等分， 屏宽变化时 4 项始终平分整条导航；真正使用时它是页面底部固定定位的那一条。

5. 导航用到的符号对照

首页#lxy_icon_home · shouye
分类#lxy_icon_cat · catalog
购物车#lxy_icon_cart · cart-full
我的#lxy_icon_me · interests

6. 徽章、红点与两种方案对比

.lxy_num 数字徽章与 .lxy_dot 右上角红点的写法与 13-3 完全相同： 绝对定位挂在图标盒子上，红底白字、白色描边，尺寸同样用 clamp() 自适应。 点击导航项可切换选中态，图标颜色由 color 经 fill: currentColor 联动。

两种方案对比：字体图标（13-3）像文字一样用 content 输出， 字号即可控制大小；SVG（本页）是真正的矢量元素，用 width / height / fill 控制，无需加载字体文件，也不会出现字体闪烁。
