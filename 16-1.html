📦 当前数组

🔴 修改原数组（Mutating）— 直接改数组本身

push() Mutating

在末尾加一个或多个元素，返回新长度。

const len = arr.push(7);
// 末尾多了个 7，len = 新长度
等待运行…
pop() Mutating

弹出最后一个元素，原数组变短。

const last = arr.pop();
// last = 最后那个元素
等待运行…
shift() / unshift() Mutating

shift 从头部弹出；unshift 在头部插入。

const first = arr.shift();
arr.unshift(0); // 头部加 0
等待运行…
splice() Mutating

万能方法 —— 从 start 开始删 count 个，再插入新元素。

arr.splice(start, count, ...items);
// 返回被删除的数组
等待运行…
reverse() Mutating

原地翻转数组顺序。

arr.reverse();
// 首尾互换
等待运行…
sort() Mutating

排序 ⚠️ 默认按字符串排！数值要传比较函数。

// 升序排序
arr.sort((a, b) => a - b);
等待运行…

🔵 不修改原数组（Non-mutating）— 返回新数组

map() Non-Mutating

对每个元素做变换，返回新数组（长度不变）。

const doubled = arr.map(x => x * 2);
等待运行…
filter() Non-Mutating

挑出满足条件的元素，返回新数组（长度可变）。

const big = arr.filter(x => x > 3);
// 只留大于 3 的
等待运行…
reduce() Non-Mutating

把数组折叠成一个值（求和、求最大、累加器…）。

const sum = arr.reduce(
  (acc, cur) => acc + cur, 0
);
等待运行…
slice() / concat() Non-Mutating

slice 切片（左闭右开）；concat 拼接。都不改原数组。

const mid = arr.slice(2, 5);
const all = arr.concat([100, 200]);
等待运行…
indexOf() / includes() Non-Mutating

查位置 / 查是否包含。includes 更语义化，返回布尔值。

arr.indexOf(5);     // 索引 or -1
arr.includes(5);  // true/false
等待运行…

🟡 迭代（Iteration）— 遍历每个元素

forEach() 迭代器

对每个元素执行一次回调，不返回任何东西（只是副作用）。常用于打印、累加、DOM 操作。

arr.forEach((val, i) => {
  console.log(`arr[${i}] = ${val}`);
});
