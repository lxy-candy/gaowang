CSS 变量（自定义属性）演示

CSS 变量以 -- 声明，通过 var() 读取；在选择器中重新赋值即可实现一键换肤。

1. 在 :root 中声明全局变量

页面的颜色、圆角、阴影都来自变量，修改一处即可全局生效。

:root {
    --lxy-primary: #409eff;
    --lxy-radius: 8px;
}
h2 { border-left: 4px solid var(--lxy-primary); }

4. var() 默认值与 calc() 计算

拖动滑块修改变量 --lxy-size，方块尺寸通过 calc(var(--lxy-size) * 1px) 实时计算：

.lxy_preview {
    width: calc(var(--lxy-size, 60) * 1px);  /* 带默认值 60 */
    background: var(--lxy-primary);
}
