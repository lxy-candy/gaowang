📘 对象（Object）— 键值对的世界

Object.keys / values / entries 静态方法

分别拿到所有键、所有值、[键, 值] 二元组数组。

Object.keys(obj);
Object.values(obj);
Object.entries(obj);

in / hasOwnProperty 查询

`in` 看原型链，`hasOwnProperty` 只看自身。

"name" in obj;
obj.hasOwnProperty("name");

📝 字符串（String）— 字符的海洋

length / charAt / 索引 基础

字符串可以像数组一样用 [i] 取字符，.length 是长度。

str.length;    // 长度
str.charAt(0); // 第 0 个字符
str[7];       // 索引也可以
等待运行…
indexOf / includes / startsWith / endsWith 查找

查找子串位置 / 是否包含 / 是否开头 / 是否结尾。找不到 indexOf 返回 -1。

str.indexOf("Java");
str.includes("script");
str.startsWith("Hello");
str.endsWith("Script");
等待运行…
slice / substring 截取

slice 支持负数索引（从末尾数），substring 不支持。字符可视化区会高亮被截取的部分。

str.slice(0, 5);    // "Hello"
str.slice(-6);       // 末尾 6 个
等待运行…
toUpperCase / toLowerCase 大小写

全部转大写 / 小写。不改变原字符串（字符串是不可变的）。

str.toUpperCase();
str.toLowerCase();
等待运行…
trim / trimStart / trimEnd 空白

去掉首尾空格。常用于表单输入清洗。

const dirty = "  hello  ";
dirty.trim(); // "hello"
等待运行…
split / join 数组互转

split 把字符串切成数组；join 把数组拼回字符串（属于 Array 方法）。

str.split(" ");  // 按空格切开
arr.join("-");  // 用 - 拼接
等待运行…
replace / replaceAll 替换

replace 默认只替第一个匹配，replaceAll 才会全替。也支持正则。

str.replace("l", "L");
str.replaceAll("l", "L");
等待运行…
repeat / padStart / padEnd 填充

repeat 复制 N 遍；padStart / padEnd 在指定长度内用某字符填充。

"ha".repeat(3);  // "hahaha"
"7".padStart(3, "0"); // "007"
